# Telegram Google Drive Link Generator Bot

A Telegram bot that generates personalized Google Drive backup links.

## Features
- Channel membership verification
- Generate personal links
- Admin statistics
- Broadcast messages

## Deploy on Railway
[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/deploy)

## Commands
- `/start` - Start the bot
- `/generate` - Generate your personal link
- `/mylink` - View your generated link
- `/help` - Get help
- `/stats` - Admin statistics
- `/broadcast` - Broadcast messages (Admin only)
